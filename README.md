# ABYSS — 심해 낚시 일지

공유 채팅의 기획을 바탕으로 새로 구현한 로컬 게임입니다. 이전 프로젝트의 원본 복원본은 아닙니다. 공유 이미지 다운로드가 브라우저 승인 단계에서 거절되어 현재는 새로 그린 픽셀 아트를 사용합니다. 원본 이미지 적용은 미완료이며 자세한 대조 결과는 요청-대조표.md를 참고하세요.

## 실행

Node.js 22.12 이상과 pnpm을 설치한 환경에서 이 폴더를 열고 실행합니다.

```sh
pnpm install
pnpm dev
```

표시되는 로컬 주소를 브라우저에서 엽니다. 기본 주소는 http://127.0.0.1:5173 입니다.

```sh
pnpm test
pnpm build
pnpm preview
```

## 게임

- Phaser 4.2.1, TypeScript, Vite.
- 5개 해역, 50종 물고기, 10단계 희귀도(일반~심연), 2.5% 황금 변종.
- 첫 3초 준비 후 추적·타이밍·위치 유지·리듬 연타·릴 장력 조절 미니게임을 진행합니다. 등급에 따라 최대 5라운드이며, 연속 라운드는 짧게 연결됩니다. 마우스·터치·키보드 지원.
- 10마리 포획 후 보스 도전. 타이밍 클릭·길게 누르기, 즉시 재도전. 첫 처치 보상 1회.
- 낚싯대와 어선 5단계. 그물 쿨다운 18/15/12/9/7초.
- 보스 처치와 양쪽 장비 강화로 해역 해금. 이전 해역 재방문.
- 도감, 어종 연구 보상, 자동 저장 및 JSON 기록 내보내기·가져오기.
- 포획·그물·보스전마다 경험치 획득, 선장 레벨과 레벨업 골드 보상.
- 매일 갱신되는 3개 의뢰와 골드·경험치 보상. 도감 완성 뒤에도 수집 의뢰가 계속 진행됩니다.
- 시스템 마우스 포인터를 항상 표시하고 게임 위에서는 조준 커서로 구분합니다.
- 완주형 심해 원정: 5개 해역, 해역별 2회 경로 선택, 안전·위험 낚시터, 난파선 유물, 선체 수리, 보스 결전.
- 출항 장비와 유물 빌드, 선체 3칸. 실패해도 도감·포획 기록은 남고, 완주 횟수와 최고 전리품 점수를 저장합니다.
- FIFA식 강화 흐름을 적용한 어종 미페 카드: 다른 어종 카드도 최대 3장까지 희생 재료로 선택해 +11까지 강화하며, 희귀한 재료일수록 성공 확률이 크게 오릅니다. 실패 누적 보정과 기본 카드 보호도 적용됩니다.
- 강화 실패 시 재료 카드가 소모되고 강화 단계가 한 단계 하락합니다. +1에서 실패하면 BASE로 떨어지며, 실패 보정은 유지됩니다.
- 실시간 어시장: 50종 물고기 분 단위 시세, 일일 한정 재고, 급등 어종, 검색·해역·등급·가격 필터, 1장/3장 매입과 중복 카드 매도.
- 시장 구매 카드는 강화·도감에 쓸 수 있지만 포획·의뢰·보스 진척에는 반영하지 않습니다. 매도할 때는 어종별 기본 카드 한 장을 보호합니다.
- 실시간 어시장: 50종 물고기 분 단위 시세, 일일 한정 재고, 급등 어종, 검색·해역·등급·가격 필터, 1장/3장 매입과 중복 카드 매도.
- 시장에서 산 물고기는 강화·도감에 쓰이며 포획·의뢰·보스 진행에는 반영하지 않습니다. 매도할 때는 어종마다 기본 카드 한 장을 보호합니다.
- 강화한 미페를 낚싯대에 결합하면 포획 구역·타이밍 판정·골드 보너스가 증가하고 +4부터 낚시 라운드가 줄어듭니다. 결합 해제와 교체도 가능합니다.
- 해역 보스마다 변형 패턴: 가짜 불빛, 위치 이동, 빠른 타이밍, 잦은 홀드 공격.
- 배 흔들림, 해류·기포·열수 연기·발광, 갈고리·끌어올리기·그물 애니메이션, 콤보·골드 팝업·스파클, 보스 확대·포효, 암전 해역 소개, 효과음 토글.

저장은 브라우저의 localStorage를 사용합니다. 주소 또는 브라우저가 바뀌면 다른 저장 공간을 사용하므로 플레이 안내의 내보내기로 기록을 보관하세요. 서버를 중지해도 기록은 남습니다.

폰트는 Google Fonts를 사용하며, 네트워크가 없으면 기본 글꼴로 표시됩니다. 게임 자체와 그래픽에는 외부 리소스 연결이 필요하지 않습니다.
